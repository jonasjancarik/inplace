inplace opens a hand-written HTML document in your agent's browser so you can fix the wording right where you read it. For anything bigger, leave a comment on the page and the agent changes the same file. Nothing is converted, and your layout stays exactly as it was.

You fix a sentence on the page, then ask for a new row. The agent finds the table by its id, edits the file, and the page reloads.

Why not just use a rich-text editor?

Agents now write documents as hand-crafted HTML, with real typography, colour-coded tables, charts and print layouts. Rich-text editors turn that into their own format and lose half of it. inplace leaves the file alone and only lets you change what you can see.

One

The HTML file is the document

There's no editor format, database or export step. What you see in the browser is the file on disk, and what you print or send is that same file.

Two

Your edits touch one block

Typing changes the text inside a single paragraph, heading, list item or table cell. CSS, SVG charts and the rest of the markup stay byte-for-byte as they were, so a diff shows exactly what you changed.

Three

Comments point at the right place

Every block and table gets a stable data-id. When you comment on an element in your agent's browser, the agent gets that id and finds the exact spot in the file, even after the wording has changed.

Four

You can both work at once

Edits to different blocks never get in each other's way. If the agent rewrites the paragraph you're typing in, your save is refused instead of overwriting its text, and what you typed goes to your clipboard.

Get started

You need Node.js 22 or newer and an agent with a built-in browser, such as Claude Code in the Claude app or Codex.

  1. Give your agent the skill

    It teaches the agent to start inplace, find commented elements by their id, keep the ids intact, and check totals and charts after you change a number.

    npx skills add jonasjancarik/inplace

  2. Open your document

    Ask the agent to open it in inplace, or start it yourself and open localhost:8765 in the agent's browser.

    npx github:jonasjancarik/inplace path/to/document.html

  3. Type, or leave a comment

    Click into any paragraph, heading or table cell and type; changes save after a short pause. For new sections, rows, layout or charts, comment on the element and let the agent do it.

What happens to your file

The first time the page opens, inplace adds a data-id to each block and container that doesn't have one. The ids don't change how the page looks or prints, and existing ids are never renamed.

After that, the file only changes when you type, and then only inside the block you typed in. If the document is in git, every edit shows up as a small, readable diff.

Good to know

Text on the page, structure through the agent

You change the words. Adding paragraphs or rows, styling and charts are the agent's job, asked for with a comment.

Numbers don't recalculate

If you change an amount that feeds a total or a chart, the agent updates the rest. Mark values you want frozen with data-locked.

Made for your own computer

It serves one document with no login. Keep it on a network you trust, or start it with --host 127.0.0.1.
